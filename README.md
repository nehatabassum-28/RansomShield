\# RansomShield



\## Behavior-Based Early Ransomware Detection and Automated Response System



RansomShield is a cybersecurity prototype that continuously monitors a user-designated protected folder and detects ransomware-like file behavior.



Instead of relying only on file signatures, RansomShield analyzes suspicious behavioral patterns such as rapid file modifications, mass file renaming, and extension changes.



\## Key Features



\- Continuous monitoring of a protected folder

\- Behavior-based ransomware detection

\- Risk scoring from 0–100

\- Detection of rapid file modifications

\- Detection of mass file renaming

\- Detection of suspicious extension changes

\- Real-time web dashboard

\- Critical threat alerts

\- Automatic Protection Mode

\- Safe quarantine copies of affected files

\- Incident reports in JSON format

\- Incident history

\- Safe ransomware behavior simulator for demonstrations
